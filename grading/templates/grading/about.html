About the Feedback Generation Workflow

This app uses a multi-pass workflow so each model call has one narrow job. That improves reliability, especially on smaller or older models.

Evidence first Plan before prose Consistency pass Optional final refinement

Workflow Diagram

1. Build Context

Collect assignment description, rubric, instructor notes, student adjustments, and sampled artifact text.

2. Evidence Pass

Extract only supported observations: strengths, issues, and missing evidence.

3. Evaluation Pass

Convert evidence into a concise action plan and scoring notes.

4. Narrative Pass

Generate student-facing HTML feedback with clear sections and rubric alignment.

5. Consistency Pass

Remove unsupported claims, tighten wording, and keep structure intact.

Step-by-Step Description

  1. Context assembly limits prompt size while preserving enough evidence for grading.
  2. Evidence extraction prevents the model from inventing claims before writing feedback.
  3. Evaluation planning makes improvements and next actions concrete and teachable.
  4. Narrative synthesis produces the final student-facing feedback in clean HTML.
  5. Consistency review validates that final text still matches evidence and rubric intent.

When enabled, this multi-pass mode runs on regenerate. The existing second-pass refinement can still be added after it.
